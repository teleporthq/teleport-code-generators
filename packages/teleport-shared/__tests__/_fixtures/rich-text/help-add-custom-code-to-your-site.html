To add a script, style or tag to every page of a TeleportHQ site, open Project Settings → Custom Code, choose Head or Body, paste the code and click Save Changes. Then publish your site. The code runs on your published (and downloaded) site, not inside the TeleportHQ editor.

Before you start

  • You need permission to change project settings (Owner, Admin or Designer role).
  • Get the full code snippet from the tool you're adding, including its opening and closing tags, for example <script> and </script>.
  • Head or Body? Follow the tool's instructions. As a rule:
    • Head: <meta>, <link> and <style> tags, and scripts the tool says to put in the head (many analytics tools).
    • Body: scripts the tool says to put in the body, such as chat widgets.
  • The settings page lists the tags you can add here: link, meta, style and script.
  • For fonts, use Project Settings → Fonts instead. See How to upload your own fonts.

Steps

  1. In the editor, at the top left, click the TeleportHQ logo (tooltip Project Menu).
  2. Click Project Settings.
  3. In the settings menu on the left, click Custom Code.
  4. Scroll to the Custom code section.
  5. Click Head or Body.
  6. Paste your code into the code box. For example, a chat widget:
    <script src="https://widget.example.com/chat.js" async></script>
  7. Click Save Changes. The message "The changes have been saved" appears.
  8. Go back to the editor and publish your site. See How to publish your site.

You can also reach Project Settings from the drop-down next to the project name at the top of the editor, or from the … menu on the project card on the dashboard.

Check that it worked

Open your published site in a new browser tab. The tool should work there, for example the chat bubble appears. To confirm the code is on the page, right-click the page, choose View page source, and search for part of your snippet.

Troubleshooting

The code doesn't work in the editor That's expected. TeleportHQ doesn't run custom code on the editor canvas: "You will not be able to interact with the 3rd party code while editing your project in the playground, this will only work on your published websites." Publish and test on the live site. The code doesn't work on my live site

  • Publish again. Saving settings doesn't update the live site by itself.
  • Check you pasted the whole snippet, including opening and closing tags.
  • Check the tag type: this box is meant for link, meta, style and script tags. To place visible HTML (a table, a form, an iframe) in one spot, use a Code Embed element instead.

My site layout broke after adding code The settings page warns: "WARNING: Invalid code added here might break your website." Remove the code you added, click Save Changes, publish again, and check the snippet with the tool's provider.

The Save Changes button is greyed out You haven't changed anything since the last save. Edit the code, then save.

"Could not save changes" Try again. If it keeps failing, reload the page, and check your role allows changing project settings.

Good to know

  • Custom Code vs Code Embed: Custom Code applies to every page and adds nothing visible. A Code Embed element puts code in one place on one page, like a booking calendar. See How to add your own HTML or JavaScript with Code Embed.
  • Google Analytics and Google Tag Manager have their own fields in the Google section at the top of the same tab. See How to add Google Analytics or Google Tag Manager.
  • Tracking pixels such as Meta or TikTok go in this Custom Code box. See How to add a tracking pixel (Meta, TikTok, LinkedIn).
  • Custom code is included when you download your site's code.
