TeleportHQ creates three files for search engines and AI tools each time you publish: sitemap.xml (a list of your pages), robots.txt (rules for search engine crawlers) and llms.txt (a summary of your site for AI assistants). You don't need to upload anything. To change them, open Global SEO Settings, edit the settings, click Save Changes and publish.

Before you start

  • The sitemap and robots.txt are available on every TeleportHQ plan.

  • LLMS.txt needs a trial or a paid plan. On other plans it shows a PRO label and no llms.txt file is published.

  • The files only exist on your published site, at yoursite.com/sitemap.xml, yoursite.com/robots.txt and yoursite.com/llms.txt.

Open the settings

  1. In the left sidebar, click the layers icon (tooltip Pages, Components & Treeview).
  2. In the Pages list, right-click any page. You can also hover over it and click ….
  3. Click Global SEO Settings. The Global SEO Settings window opens.

You'll find the same settings in Project Settings → SEO.

Sitemap

The TeleportHQ sitemap lists every page search engines should find, so they discover new pages faster.

  1. Check that Automatically Generate Sitemap is switched on. It's on by default.
  2. Click Save Changes.
  3. Publish your site.

The sitemap lists your pages and one address per item on details pages, for example one per product or blog post. It leaves out pages with No Index turned on, your 404 page and admin panel pages. On a multilingual site, it lists each language version.

Robots.txt

The TeleportHQ robots.txt tells search engines which parts of your site they may visit. The default allows everything and points to your sitemap:

User-agent: Googlebot
Disallow: /nogooglebot/

User-agent: *
Allow: /

Sitemap: {{domain_url}}/sitemap.xml

When you publish, {{domain_url}} is replaced with your site's address.

  1. Click inside the Robots.txt editor.
  2. Edit the rules. For example, to keep crawlers out of a /drafts folder, add Disallow: /drafts/ under User-agent: *.
  3. Click Save Changes.
  4. Publish your site.

Important: A wrong rule, like Disallow: / under User-agent: *, hides your whole site from Google. To hide single pages, use No Index instead. See How to hide a page from Google, set a canonical URL or redirect a page.

LLMS.txt

The TeleportHQ llms.txt file helps AI assistants like ChatGPT and Claude understand what your site offers. Pick one of three modes next to LLMS.txt:

  • Auto (default): TeleportHQ writes the file from your pages and updates it on every publish. You can read it, but not edit it.
  • Edit: you write the file yourself. Click Generate to start from TeleportHQ's version, then change the text.
  • Off: no llms.txt file is published.

Then click Save Changes and publish.

Check that it worked

After publishing, open your live site and add /sitemap.xml, /robots.txt or /llms.txt to the address, for example https://sweet-crumbs.teleporthq.app/robots.txt. You see the file's content. To help Google find your pages sooner, submit the sitemap address in Google Search Console.

Troubleshooting

My changes don't show in the file Check that you clicked Save Changes and then published. The files are only rebuilt when you publish.

The file shows old content I uploaded before If your project has a file named robots.txt, sitemap.xml or llms.txt in its uploaded files, TeleportHQ publishes that file and doesn't create its own. Delete the uploaded file from the Assets Manager, then publish. See How to rename or delete files.

A page is missing from the sitemap Check whether No Index is on for that page in Page SEO Settings. Pages with "404" or "not-found" in their name are also left out.

LLMS.txt shows a PRO label llms.txt needs a trial or paid plan. See What's the difference between Trial, Pro and Premium?.

Good to know

  • Turning off the sitemap stops TeleportHQ from publishing sitemap.xml. The robots.txt default still points to it, so update the Sitemap: line too.
  • The robots.txt editor can't be empty. If you delete everything, the default rules come back.
  • Site Health audits check these files. A missing robots.txt or sitemap.xml shows up as an issue. See How to check your site's SEO health.
