# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue or pull request: write to hello@teleporthq.io.

Tell us what you found, how to reproduce it, and which package and version it affects. We aim to reply within five working days and keep you informed until a fix is released.

The same contact covers the TeleportHQ platform and the projects these generators produce.

## Supported versions

Fixes go into the latest published release of the `@teleporthq/teleport-*` packages. Earlier releases are not patched.
