The TeleportHQ editor has keyboard shortcuts for editing, selecting, adding elements, zooming and opening panels. On Windows, use Ctrl and Alt; on a Mac, use Cmd (⌘) and Option (⌥). To see a shortcut sheet inside the editor, press Ctrl+Shift+/ (Cmd+Shift+/ on a Mac), or open Project Menu → Help → Keyboard Shortcuts.

How TeleportHQ shortcuts work

  • Focus matters. Most shortcuts work when the canvas or the layers tree is active. Click an empty part of the canvas first. While you're typing in a text element or a settings field, the keys type text instead.
  • Mac and Windows. Every "Ctrl" shortcut below uses Cmd on a Mac, and every "Alt" uses Option.
  • The in-app sheet. The keyboard icon at the bottom of the left sidebar also opens the Keyboard Shortcuts sheet, with tabs Control, View, Elements and Others. This article lists the shortcuts that work in the editor today, including some that aren't on the sheet.
  • No save shortcut needed. TeleportHQ saves your work automatically, so Ctrl+S does nothing.

Editing

Copy Ctrl+C ⌘C
Cut Ctrl+X ⌘X
Paste Ctrl+V ⌘V
Paste style (copy the look of the copied element) Ctrl+Alt+V ⌘⌥V
Duplicate Ctrl+D ⌘D
Group selected elements into a container Ctrl+G ⌘G
Ungroup Ctrl+Shift+G ⌘⇧G
Delete Delete or Backspace ⌫
Add or edit a link Ctrl+K ⌘K
Start editing the selected element (for example, its text) E E
Move the element before or after its neighbor Arrow keys Arrow keys

Arrow keys move the element left or right in a row, and up or down in a column. See How to copy, paste and duplicate elements.

Action Windows Mac

Adding elements

Select a container on the canvas, then press a letter. The element is added inside the selected element. These keys don't work inside a component copy (instance) on a page.

Key Adds
R Row
C Column
T Text
H Heading
L or K Link
B Button
I Image
V Video
D Date
S Slot (only while editing a component)
