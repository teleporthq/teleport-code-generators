In TeleportHQ, you add your own CSS animation in two parts. First, paste the animation's @keyframes inside a <style> tag in Project Settings → Custom Code → Head and click Save Changes. Then select an element and, in the right panel's Advanced tab, add an animation property that uses the animation's name. Custom code runs on your published site, not on the editor canvas.

Before you start

  • This is for people comfortable with CSS. For animations without code, see Which animation options does TeleportHQ have?
  • You need permission to change project settings.
  • Custom code isn't limited by plan.
  • The 98 effects in the Animation section already come from the animate.css library, so you don't need to add that library to use them. See How to animate an element when it scrolls into view.

1. Add your keyframes

  1. In the editor, at the top left, click the TeleportHQ logo (tooltip Project Menu).

  2. Click Project Settings.

  3. In the settings menu on the left, click Custom Code.

  4. Under Custom code, click Head.

  5. Paste your animation inside a <style> tag. For example:

    <style>
  @keyframes softPulse {
    0% { transform: scale(1); }
    50% { transform: scale(1.05); }
    100% { transform: scale(1); }
  }
</style>

  6. Click Save Changes.

2. Use the animation on an element

  1. Go back to the editor and select the element. For example, an Order now button.
  2. In the right panel, open the Advanced tab.
  3. In the empty row, type animation in the property field.
  4. Type softPulse 2s infinite in the value field.
  5. Click + to add the row.

To reuse the animation on many elements, add the same animation property to a CSS class instead, in the class's Properties. See How to edit a CSS class.

Add an animation library

To load another library, such as a scroll-animation script, paste its <link> or <script> tag from the library's documentation into Head (or Body for scripts that should load last), then click Save Changes. Follow the library's own instructions for the class names or attributes it needs.

Check that it worked

Custom code doesn't run on the TeleportHQ canvas, so the element stays still while you edit. Publish your site and open it to see the animation. See How to publish your site.

Troubleshooting

The animation doesn't play on my published site Check that the name in the animation value matches the @keyframes name exactly, including capital letters. Then check that you clicked Save Changes and published again after adding the code.

My site looks broken after adding code The settings page warns: "WARNING: Invalid code added here might break your website." Remove the code you added, click Save Changes, and publish again. Then add it back one piece at a time.

Good to know

  • Code in Head is added to every page of your site.
  • For custom fonts, don't use custom code. Use Project Settings → Fonts. See How to upload your own fonts.
